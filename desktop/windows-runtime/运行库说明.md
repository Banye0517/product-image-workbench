# Windows运行库

ONNX Windows x64原生库依赖Microsoft Visual C++ v14 x64运行库。缺少该运行库时，工作台会给出明确的下载与安装提示。由使用者或单位IT从微软官网下载并安装，工作台不自动安装。

官方下载：https://aka.ms/vc14/vc_redist.x64.exe
官方说明：https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

微软对运行库再分发存在Visual Studio许可条件。本项目不把安装器或DLL塞入下载包，在未核实开发许可前仅提供官方获取入口。
