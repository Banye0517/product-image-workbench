# 主图与双尺寸同步实施计划

目标：保留旧详情记录，新增共享素材的主图页，编辑一份内容并导出两种规格。
架构：主图内容与两个尺寸的位置分开存储。照片使用既有缓存预览、原图导出。抠图独立后台任务，不修复或生成商品细节。
技术：React、Konva、Sharp、Electron、macOS Vision。

- [x] 共享模型：四种模板、双尺寸布局、默认Logo、字段与素材校验，先写同步与数量约束测试。
- [x] 服务端：接受所有方向图片、主图和详情独立保存、双尺寸导出、Apple Vision本机抠图与缓存。
- [x] 主图组件：可编辑字号/文案、拖动叠层、切图/缩放、标签颜色/吸色、6选3图标、可开关透明渐变。
- [x] 工作台接入：文案下面切换入口与保存状态、文件操作右上角图标、白底选图、保存与批量导出。
- [x] 验证：旧记录迁移、全部方向导入、双尺寸导出像素、保存隔离、主图实际界面操作和两张商品抠图检查。
- [x] 交付：中文说明、验收记录、Apple芯片本机包，保持用户正在编辑的应用。

已批准规则：渐变左色右透明；最多3个icon；只有颜色展示模板可多张；白底只抠图不修图；750版同步内容并允许单独调整位置；每次导出询问位置。
