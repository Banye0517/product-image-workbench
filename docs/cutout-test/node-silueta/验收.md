# 工作台实际运行引擎验收

使用onnxruntime-node 1.30.0与Silueta，复用模型会话；Windows桌面入口使用此处理器，Mac保留Vision。

本机Node测试：首次上衣1.366秒、再次0.324秒；裤子0.325、0.327秒。输入来自1200宽工作缓存，计时包含模型初始化（首次）、读取、推理和保存透明PNG。
本机Electron以Node模式测试：首次0.381秒、再次0.304秒；裤子0.312、0.311秒。
