# Windows候选本机模型测试

使用rembg 2.0.85、ONNX Runtime 1.31.0、birefnet-general-lite，CPUExecutionProvider。模型约224MB，下载与推理都在本机执行；测试未上传商品照片。

本轮测试机器为Mac，不是Windows。上衣输入792×675；裤子原照片等比缩小到1200×1200。只生成透明蒙版，没有生成或修补衣物。

初次默认线程推理：上衣38.16秒、裤子74.4秒；模型首次下载和加载共307.07秒。
使用OMP_NUM_THREADS=2后：已有模型加载2.04秒，上衣7.09秒、裤子14.84秒。测试仅两张，未作Windows或其他电脑的速度承诺。

上衣外轮廓基本完整。裤子外背景去除，但衣架、挂钩、夹子以及衣架内部白色区域保留，去衣架测试失败。结果分别为top.png、pants.png，均为透明PNG；*-check.jpg添加蓝灰背景便于看边缘，不是白底导出成品。

结论：可作为Windows本机抠图候选，但本轮仅样图试验，尚未集成Windows组件。不能保证秒出和自动去衣架。仍可用已抠好的透明PNG完成白底图。
