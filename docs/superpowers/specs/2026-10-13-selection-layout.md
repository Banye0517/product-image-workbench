# 分组选图与可移动图片

用户已确认：导入后、添加文案前，自动展示分组选图；小图/大图可切换，点击照片放大。最终选择约10张，不将不需要照片误判为重复，不改动摄影原文件。确认选择后生成单图卡片，可继续添加组合卡片。

单图保持当前摄影比例、宽750；三图整体750×1200。各图片可在区域内拖动、等比例缩放，露出背景。卡片背景支持手动取色和在照片上点击吸色。单图文字和Logo与图片移动分模式，避免误拖。

固定Logo使用用户原始299×65透明PNG，等比例缩放。组合不含文字或Logo。大图查看使用750宽缓存，不宣称原始分辨率检查。分组选图后台处理完成后才可确认，过程中可以浏览。
