# 单图渐变、文字颜色、抗菌图标及Windows抠图方案

详情页单张图新增可选渐变遮罩，默认关闭。顶部颜色支持吸取照片颜色及填写色号，向下渐变至透明。遮罩宽750px固定，高度可调1–1220px，起点为画布y=40。照片和渐变一并按图片区20px圆角裁切，顶部40px保持白色。照片拖动和吸色不受遮罩阻挡，文案及Logo在遮罩上方。预览与导出一致。

新建详情主副文案、组合标题、主图大文案、小文案、标签统一默认黑色，所有文字支持选择白色。已有主动设置的颜色保留，固定PNG图标内文字不改色。

将用户提供的5A抗菌PNG加入公共图标库，主图首图从7个图标中选择最多3个，两个规格共用选择。

Windows抠图建议先试验rembg和明确指定的BiRefNet本地模型，避免使用需要额外商业协议的默认BRIA模型。仅生成透明蒙版，不生成或修补商品；保留原图和弃用结果的选项。以现有上衣及裤子测试边缘，衣架分离不保证。先做模型许可和样图验证，再决定集成；未授权前不安装或下载模型。可选独立组件有利于控制主程序包体，组件应维持一个推理会话避免每张重载。

本轮不生成安装包，待用户明确要求时再打包。Windows真机验收依然必要。
