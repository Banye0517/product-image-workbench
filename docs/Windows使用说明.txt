商品图工作台 1.1.5 — Windows x64 使用说明

适用系统：Windows 10/11，Intel 或 AMD x64 电脑。

安装与启动
1. 将整个 ZIP 解压到本机磁盘，不要在压缩包内直接运行。
2. 打开“商品图工作台.exe”。保留解压目录中的其他文件和 DLL，不要只复制 EXE。
3. 选择本机产品图片目录开始工作。原素材不会被删除或覆盖。
4. 首次启动若提示缺少 Microsoft Visual C++ x64 运行库，请确认已完整解压，再从微软官方地址下载并由使用者安装：https://aka.ms/vc14/vc_redist.x64.exe。单位电脑可联系 IT 安装；程序不会静默安装运行库。

主要功能
- 按产品目录导入图片、查看重复候选、筛选与恢复被排除的工作素材。
- 编辑详情单图、三图组合、搭配推荐和 800×800 / 750×1000 主图。
- 拖动照片、文案、Logo、标签调整位置；使用缩放、裁切、吸色和渐变工具。
- 800×800 主图的字段改动单向同步到 750×1000；竖版可以独立调整，不回写方图。
- 使用内置图标、本机缓存、保存草稿和批量导出。
- 使用 Silueta ONNX 快速模型本机抠图。无需安装 Python，不上传照片；可预览并弃用结果。与商品连在一起的衣架、夹子可能保留。

保存与导出
原始照片保持只读。项目记录与图片缓存保存在当前 Windows 用户的数据目录，不会自动同步给其他同事。请选择原素材目录之外的成品保存目录；再次导出不会覆盖已有文件，会增加序号。

升级
在旧版保存并退出，然后将新版解压到独立文件夹运行。同一 Windows 用户的项目记录会沿用；不同 Windows 用户之间不会自动共享。

兼容性说明
本 Windows x64 包在 macOS 上交叉构建；已经检查 Windows 包结构和图片处理依赖，但尚未在 Windows 真机启动验证，也未进行代码签名。若系统或企业安全软件阻止运行，请按单位软件管理流程处理，不要关闭安全防护。
